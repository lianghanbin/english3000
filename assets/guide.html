English 3000 使用说明

English 3000 是一套“词表即学习对象”的英语学习工具：选中一个词表， 学习页就学这个词表；阅读、翻译和生词收集都围绕词表闭环。数据保存在本地， AI 可以完全离线运行。

一、快速开始

  1. 打开软件，默认已选中「核心 3000」词表
  2. 在「学习」页点击开始学习，进入卡片流
  3. 按 空格 显示释义和例句，点认识或不认识
  4. 不认识的词会自动进入复习队列，下次点击「开始复习」再学
学习没有每日上限，随时可以按 Esc 退出，进度自动保存。

二、词表

  • 词表即书：每个词表独立记录未学 / 待复习 / 已掌握进度
  • 可以 AI 生成领域词表、从文章提取、导入 CSV，也可以手动添加生词
  • 左侧列表支持拖拽排序；「设为当前词表」决定学习页学哪本
  • 「重置词表进度」会把该词表的已掌握状态清空

三、阅读

  • 内置示例文章，也可用 AI 生成分级文章或粘贴文章改写
  • 高亮颜色：红色=未入词表 · 蓝色=其他词表 · 绿色=当前词表 · 黑色=已掌握
  • 左键点单词直接发音；选中一段文字后右键直接朗读
  • 右键菜单按颜色区分：红色=加入阅读词表、蓝/绿=查看所在词表、黑色=重置为未学

四、翻译

  • 全局热键（默认 Ctrl+Alt+T）打开翻译小窗；截图翻译默认 Ctrl+Alt+O（Linux 需 tesseract）
  • 小窗打开时，鼠标选中的文字会自动带进输入框
  • 翻译中遇到的不认识单词，会自动收集到「翻译生词」词表

五、AI 设置

  • 供应商可选「本地 Ollama」或「OpenAI 兼容」（DeepSeek / 通义 / GLM / Kimi 等）
  • 本地模式：服务地址填 http://127.0.0.1:11434（或内置小模型的 http://127.0.0.1:8080），模型如 qwen2.5:1.5b
  • 云端模式：服务地址填厂商地址，模型填对应模型名，API Key 按提示填写
  • 默认模型是本地小模型 qwen2.5:1.5b，日常学习够用； 长文翻译建议切换更大的模型或云端 API

六、快捷键

  • Ctrl+N 学习未学单词 · Ctrl+R 复习不认识的单词
  • 空格 显示释义 · 1 不认识 · 2 认识
  • 所有快捷键都可在「设置」页自定义

七、数据与更新

  • 所有数据保存在本地 SQLite，不会上传
  • 「设置」页可查看数据目录、检查更新；发现新版本可一键自动更新
  • 「重置全部进度」会清空所有词表的已掌握状态，词表本身不受影响
