# Product Hunt（英文）

## Headline

English 3000 — Offline-first, AI-powered English learning

## Tagline

Pick a word list, learn it, read AI-generated articles, and collect new words —
all offline, open source, and free.

## Description

English 3000 is an open-source English learning app built with C++ and Qt.
Instead of locking you into one fixed course, every word list is a learning
object: choose the built-in Oxford 3000, generate a domain list with AI,
extract words from articles, or import your own CSV.

### Highlights

- Learn & review: study unseen words, then review the ones you missed
- AI-generated examples, word lists, and graded reading articles (local model,
  no account needed)
- Reading with 4-color vocabulary highlighting, tap-to-pronounce,
  one-tap "add to reading list"
- Global hotkey translation + screenshot translation
- Windows one-click installer bundles a local 1.5B model with automatic
  CUDA → Vulkan → CPU fallback; also works with any OpenAI-compatible API
- In-app auto-update with SHA-256 verification
- Windows / Linux / Android, GPL-3.0, no ads, no account, data stays local
