# 发布渠道文案

本目录提供各平台现成的发帖文案，复制即可发布。

| 文件                    | 平台                 | 说明                             |
| ----------------------- | -------------------- | -------------------------------- |
| v2ex.md                 | V2EX（技术版）       | 偏技术，讲架构与取舍，可接受批评 |
| appinn.md               | 小众软件             | 投稿格式：简介+截图+亮点+下载    |
| bilibili_xiaohongshu.md | B站 / 小红书         | 视频脚本与图文两种格式           |
| producthunt.md          | Product Hunt（英文） | 英文 headline/tagline + 介绍     |
| zhihu_jike.md           | 知乎 / 即刻（可选）  | 简短版，问答/动态风格            |

## 各平台注意事项

- V2EX：发在「分享创造」节点；标题不要带“求 star”；
  正文诚实列出不足（移动端还弱、模型 1.5B 有上限），评论区礼貌回复
- 小众软件：投稿邮箱 info@appinn.com，标题注明「投稿」；
  配 3~5 张截图，写清楚系统要求和下载方式
- B站：竖屏 30~60 秒演示视频最合适；标题要有钩子但别夸张
- 小红书：封面图 = 软件截图 + 大字卖点；正文 5~7 行，加 # 标签
- Product Hunt：上线当天再发；提前准备好英文演示图（1280×720）

## 发布前检查清单

- [ ] 截图均为最新版本界面
- [ ] 下载链接指向 v1.1.0（win-oneclick / win-latest / android-latest）
- [ ] 说明“本地模型 1.5B 够日常用，长文翻译建议云端 API”
- [ ] 说明“数据本地保存、开源 GPL-3.0”
- [ ] 留好反馈渠道（GitHub Issues）
