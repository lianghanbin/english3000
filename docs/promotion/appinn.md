# 小众软件（appinn）投稿文案

## 投稿标题

English 3000：本地 AI 驱动的开源英语学习软件（Windows / Linux / Android）

## 正文

English 3000 是一款以“词表即学习对象”为核心的英语学习软件。
选中一个词表，学习页就学这个词表；阅读、翻译、AI 生成的文章和生词收集
全部围绕词表闭环，数据保存在本地，AI 可以完全离线运行。

### 主要特点

- 学习 / 复习分离：学习没学过的词，点“不认识”自动进入复习队列
- 内置核心 3000 词表，也可用 AI 生成领域词表、从文章提取、导入 CSV
- 阅读文章四色高亮：当前词表 / 其他词表 / 已掌握 / 未入表
- 全局热键翻译 + 截图翻译，生词自动收进独立词表
- Windows 一键安装包内置 Qwen2.5 1.5B 小模型（CUDA/Vulkan/CPU 自动回退），
  也支持 DeepSeek、通义、GLM、Kimi 等 OpenAI 兼容云端 API
- 应用内自动更新，下载校验后自动安装
- GPL-3.0 开源，免费无广告，无账号
